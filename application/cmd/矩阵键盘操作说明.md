# 自动核素分药仪矩阵键盘操作说明

## 一、使用说明

本说明供设备安装、售后维护和现场操作人员使用。使用时不需要了解设备程序，只需找到 LCD 当前显示的页面，按照该页面的操作说明按键即可。

操作时请遵守以下规则：

- 一次只按一个键，按下后松开，再按下一个键。
- 同时按两个或多个键时，设备不会执行本次操作。
- 长按不会连续触发。如需重复输入数字或重复点动，请逐次按下并松开。
- 当前页面不支持的按键，按下后没有反应，这是正常现象。
- 自动运行时不要连续快速按键，应等待屏幕内容变化或当前动作完成。
- 【清除】用于清除输入或确认退轨；【清空】会启动管路清空/冲洗，两者不是同一个功能。

## 二、键盘布局

面板按键排列如下：

| 故障  | 抽药  | 配药  | 发药  | 定量排气 | 清空  |
| --- | --- | --- | --- | ---- | --- |
| 进罐  | 出罐  | 7   | 8   | 9    | 0   |
| 插针  | 收针  | 4   | 5   | 6    | .   |
| 未使用 | 未使用 | 1   | 2   | 3    | 清除  |
| 复位  | 启动  | 暂停  | 远控  | 未使用  | 未使用 |

四个“未使用”位置没有功能，按下后不会有反应。

## 三、所有按键的作用

| 按键          | 在普通操作页面中的作用          | 在调试页面中的作用            |
| ----------- | -------------------- | -------------------- |
| 进罐          | 无                    | 进罐导轨向前移动 1 mm。       |
| 出罐          | 无                    | 进罐导轨向后移动 1 mm。       |
| 插针          | 无                    | 插针导轨向前移动 1 mm。       |
| 收针          | 无                    | 插针导轨向后移动 1 mm。       |
| 抽药          | 无                    | 每按一次切换抽水泵的开或关。       |
| 故障          | 在本机待机且设备空闲时进入调试页面。   | 停止调试动作并退出到待机页面。      |
| 配药          | 在待机页面进入配药设置。         | 无。                   |
| 发药          | 在待机页面或配药完成页面进入发药设置。  | 无。                   |
| 定量排气        | 在待机页面立即开始自动排气。       | 无。                   |
| 清空          | 在待机页面立即开始管路清空/冲洗。    | 在“退轨警告”页面取消退轨。       |
| 0、3、6、7、8、9 | 输入体积数字。              | 无。                   |
| 1           | 选择一瓶，或输入数字 1。        | 泵1吸入 3 圈。            |
| 2           | 选择两瓶，或输入数字 2。        | 泵2吸入 3 圈。            |
| 4           | 输入数字 4。              | 泵1排出 3 圈。            |
| 5           | 输入数字 5。              | 泵2排出 3 圈。            |
| .           | 输入小数点。               | 无。                   |
| 清除          | 清空当前输入；配药输入为空时返回上一步。 | 第一次按进入退轨确认，第二次按开始退轨。 |
| 启动          | 根据当前页面执行确认、开始或继续。    | 无。                   |
| 暂停          | 暂停正在运行的本机流程，或暂停远控输出。 | 无。                   |
| 复位          | 取消设置、终止本机流程或退出调试。    | 停止调试动作并返回待机页面。       |
| 远控          | 在待机页面申请上位机控制。        | 无。                   |

## 四、开机页面

### 1. 系统初始化中

开机后可能显示：

```text
自动核素分药仪
系统初始化中..
导轨回零
请等待
```

此时设备正在进行开机导轨回零。不要按键，不要触碰或阻挡导轨，等待设备自动完成。

### 2. 初始化完成

导轨回零完成后，屏幕短暂显示系统就绪。设备随后默认进入“上位机远控”页面。

### 3. 开机回零故障

如果开机时显示“故障”“导轨回零”或“严重报警”，说明导轨没有正常完成回零。

操作方法：

1. 检查导轨运动范围内是否有阻挡。
2. 检查机构和限位位置是否正常。
3. 重新上电观察。
4. 仍然报警时停止操作并进行维修检查。

### 4. 系统启动就绪

这是当前保留的页面，正常开机流程通常不会停留在这里。若屏幕显示“系统已就绪、任意键开始”，按任意一个有功能的按键即可进入待机页面。

## 五、上位机远控页面

设备开机完成后默认进入远控页面。根据连接状态，屏幕可能显示以下几种内容。

### 1. 远控申请中

屏幕显示“远控申请中”或“等待上位机”。

操作方法：等待上位机回应。此时配药、发药和调试按键不会启动本机动作。

### 2. 等待授权

屏幕显示“等待授权”或“等待上位机”。

操作方法：在上位机完成设备授权或解锁。键盘上的业务按键不能跳过授权。

### 3. 等待上位机连接

屏幕显示“等待上位机”。

操作方法：检查上位机是否启动、通信线是否连接，然后等待页面自动更新。

### 4. 上位机控制中

常见显示：

```text
--上位机远控--
PC控制中...
暂停键挂起
请先按暂停键
```

有效按键：

| 按键  | 作用                                |
| --- | --------------------------------- |
| 暂停  | 立即停止当前远控输出，进入“远控本地暂停”。            |
| 启动  | 双瓶远控配药等待换罐时，确认已经换罐并继续。其他情况下通常无动作。 |
| 复位  | 正常远控时不能直接切回本机，按下后仍停留在远控页面。        |

### 5. 远控本地暂停

屏幕显示“远控本地暂停”“等待上位机”，有时会提示“启动键继续”。

有效按键：

| 按键  | 作用                                |
| --- | --------------------------------- |
| 启动  | 恢复接收上位机命令。暂停前的动作不会自动重做，需要上位机重新下发。 |
| 复位  | 退出远控，切换到本机待机页面。                   |

### 6. 本机接管后重新申请远控

屏幕可能提示“本机接管”“远控键申请”。需要重新交给上位机时，先回到待机页面，再按【远控】申请。

### 7. 从远控切换到本机

必须按以下顺序操作：

1. 按【暂停】。
2. 等待屏幕显示“远控本地暂停”，并确认运动已经停止。
3. 按【复位】。
4. 屏幕进入“设备待机”。

不能在正常远控状态下直接按【复位】切回本机。

## 六、本机待机页面

常见显示：

```text
设备待机
活度 12.5mCi
体积 35.0ml
配药／发药
```

屏幕上的活度和体积是设备当前记录的药液信息。

有效按键：

| 按键   | 作用                   |
| ---- | -------------------- |
| 配药   | 进入配药设置。              |
| 发药   | 进入发药设置。              |
| 定量排气 | 立即开始单独排气，没有第二次确认。    |
| 清空   | 立即开始管路清空/冲洗，没有第二次确认。 |
| 故障   | 设备完全空闲时进入调试页面。       |
| 远控   | 向上位机申请远控。            |
| 复位   | 清除当前操作状态并保持在待机页面。    |

【进罐】【出罐】【插针】【收针】【抽药】和数字键在待机页面不会直接驱动设备。

## 七、配药页面

### 1. 选择药瓶数

常见显示：

```text
选择药瓶数
一瓶
两瓶
按1/2
```

操作方法：

- 按【1】选择一瓶。
- 按【2】选择两瓶。
- 按【复位】取消配药并返回待机。

当前本机操作最多支持两瓶。

### 2. 输入一号药瓶体积

常见显示：

```text
输入药量
一号:0.0ml

启动确认
```

操作方法：

1. 使用数字键和【.】输入体积。
2. 确认屏幕数值。
3. 按【启动】保存一号药瓶体积。

其他按键：

- 【清除】：输入不正确时清空整项；输入已经为空时返回瓶数选择。
- 【复位】：放弃本次配药设置并返回待机。

### 3. 输入二号药瓶体积

选择两瓶时，一号药瓶确认后显示二号输入页面。

操作方法与一号药瓶相同：输入体积后按【启动】确认。

- 输入为空时按【清除】：返回一号药瓶输入。
- 按【复位】：放弃本次设置并返回待机。

### 4. 输入注意事项

- 最多输入 5 个字符，小数点也算一个字符。
- 小数点只能输入一次。
- 首先按【.】时，设备会自动按 `0.` 输入。
- 屏幕按一位小数显示，现场操作建议输入一位小数，便于核对。
- 【清除】会清空整项，不是删除最后一位。
- 不要在没有输入有效体积时直接按【启动】。

### 5. 开始配药准备

药瓶体积输入完成后显示：

```text
开始配药
放入一号罐
准备水和杯
启动继续
```

操作方法：

1. 放好一号药罐。
2. 确认纯净水和接液容器已准备好。
3. 确认管路和机构周围无阻挡。
4. 按【启动】开始自动配药。

按【复位】可放弃并返回待机。

### 6. 自动配药—步骤1：进罐

```text
自动配药
步骤1
进罐运行
请等待
```

设备正在将药罐送入工作位置。正常情况下无需按键。

- 【暂停】：暂停流程。
- 【复位】：中止流程并进入安全收尾。

### 7. 自动配药—步骤2：插针

```text
自动配药
步骤2
插针运行
请等待
```

设备正在执行插针。正常情况下无需按键。

- 【暂停】：暂停流程。
- 【复位】：中止流程并进入安全收尾。

### 8. 自动配药—步骤3：抽水

```text
自动配药
步骤3
抽水中
请等待
```

设备正在抽取药瓶内液体。正常情况下无需按键。

- 【暂停】：暂停流程。
- 【复位】：中止流程并进入安全收尾。

### 9. 自动配药—步骤4：补水

屏幕显示“补水中”，并可能显示“已完成体积/总量”。

正常情况下等待补水自动完成。

- 【暂停】：暂停流程。
- 【复位】：中止流程并进入安全收尾。

### 10. 自动配药—步骤5：活度检测提示

屏幕可能先显示：

```text
自动配药
步骤5
活度检测
请等待
```

等待设备自动进入活度检测倒计时页面。

### 11. 换罐页面

两瓶配药时，一号药瓶完成后显示：

```text
一号完成
请换药罐
放入二号
启动继／复位停
```

操作方法：

1. 确认设备已经停止并出现换罐提示。
2. 取出一号药罐，放入二号药罐。
3. 确认药罐安装到位。
4. 按【启动】继续。

不再继续时按【复位】，设备进入中止收尾。

### 12. 活度检测倒计时

常见显示：

```text
活度检测
稳定读数
剩余:15s
请等待
```

等待倒计时结束，不需要按【启动】。

- 【暂停】：暂停当前流程。
- 【复位】：中止流程并进入安全收尾。

### 13. 活度检测完成

倒计时结束后，屏幕显示“检测完成”“计算中”，并显示活度数值；没有收到有效读数时可能显示活度读取超时。

操作方法：等待设备自动继续排气和冲洗。此时不要重复按【启动】。

### 14. 自动排气

常见显示：

```text
自动排气
泵二运行
请等待
```

可能从两种操作进入：

- 配药完成检测后自动进入。
- 待机页按【定量排气】进入单独排气。

正常情况下等待自动完成。单独排气结束后返回待机；配药过程中的排气完成后继续冲洗。

需要中止时按【复位】。

### 15. 管路冲洗

常见显示：

```text
管路冲洗
泵一运行
进度:0%
请等待
```

可能从以下操作进入：

- 配药完成后的自动冲洗。
- 发药完成后的自动冲洗。
- 待机页按【清空】启动的单独清空/冲洗。

等待进度完成。需要中止时按【复位】。

当前本机默认排气量和冲洗量均为 10.00 ml；实际设备参数如有调整，以现场配置为准。

### 16. 配药完成

常见显示：

```text
配药完成
浓度:0.125mCi
等待发药
```

有效按键：

| 按键  | 作用      |
| --- | ------- |
| 发药  | 进入发药设置。 |
| 启动  | 返回待机页面。 |
| 复位  | 返回待机页面。 |

## 八、发药页面

### 1. 发药设置

常见显示：

```text
发药设置
剩余:35.0ml
输入:0.0ml
启动开始
```

操作方法：

1. 查看屏幕显示的剩余体积。
2. 使用数字键和【.】输入本次发药体积。
3. 确认输入不大于剩余体积。
4. 按【启动】开始发药。

其他按键：

- 【清除】：清空当前输入。
- 【复位】：取消并返回待机。

### 2. 输入超过余量

如果发药体积大于剩余体积，屏幕提示：

```text
输入超过余量
```

本次输入会被自动清空。请查看剩余体积，重新输入正确数值。

### 3. 正在发药

常见显示：

```text
正在发药
泵二运行
完成:0%
```

等待进度完成。发药结束后设备自动冲洗，然后返回待机页面。

- 【暂停】：暂停发药。
- 【复位】：中止发药并进入安全收尾。

## 九、暂停和中止页面

### 1. 流程已暂停

配药、活度检测或发药时按【暂停】，屏幕显示：

```text
! 流程已暂停 !
配药流程中断
启动键继续
复位键终止
```

发药暂停时，第二行显示“发药流程中断”。

有效按键：

| 按键  | 作用                |
| --- | ----------------- |
| 启动  | 返回暂停前的页面，从暂停位置继续。 |
| 复位  | 终止当前流程并进入安全收尾。    |

### 2. 正在中止

运行中按【复位】后，可能显示：

```text
正在中止
管路冲洗
导轨复位
请等待
```

此时设备正在停止原流程、冲洗管路并让导轨回到安全位置。不要再次操作或阻挡机构，等待自动返回待机页面。

如果按【复位】时设备已经没有运行中的动作，可能直接返回待机，不显示本页面。

## 十、调试页面

### 1. 进入调试页面

在本机待机页面按【故障】。

只有在设备完全空闲、导轨和定量泵都停止时才能进入。按键后没有反应时，先确认设备已经从远控切到本机，并确认所有动作结束。

进入后常见显示：

```text
--调试模式--
导轨点动1mm
抽水泵：关
清除退轨／故障退
```

### 2. 导轨点动

| 按键  | 动作             |
| --- | -------------- |
| 进罐  | 进罐导轨向前移动 1 mm。 |
| 出罐  | 进罐导轨向后移动 1 mm。 |
| 插针  | 插针导轨向前移动 1 mm。 |
| 收针  | 插针导轨向后移动 1 mm。 |

每按一次只移动 1 mm。必须等本次移动完成并松开按键后，才能进行下一次点动。

### 3. 抽水泵开关

按【抽药】切换抽水泵：

- 显示“抽水泵：关”时按一次，抽水泵启动。
- 显示“抽水泵：开”时按一次，抽水泵停止。

退出调试或按【复位】时，抽水泵会停止。

### 4. 定量泵调试

| 按键  | 动作       | 屏幕提示 |
| --- | -------- | ---- |
| 1   | 泵1吸入 3 圈 | 水进三圈 |
| 4   | 泵1排出 3 圈 | 水出三圈 |
| 2   | 泵2吸入 3 圈 | 药进三圈 |
| 5   | 泵2排出 3 圈 | 药出三圈 |

按键后可能先显示“泵使能中”，随后执行运动。当前动作没有完成前，其他调试动作按键不会生效。

操作前必须确认管路、阀位、液源和接液容器。屏幕上的“吸入/排出”表示泵的运动方向，现场液体实际流向还会受到管路连接影响。

### 5. 退轨警告

调试主页按一次【清除】后显示：

```text
--退轨警告--
再次按下清除键
确认执行退轨
清空键返回
```

此时：

- 再按【清除】：开始退轨。
- 按【清空】：取消并返回调试主页。
- 按【故障】或【复位】：退出调试。

### 6. 正在退轨

确认退轨后依次执行：

1. 插针导轨从当前位置向后移动 120 mm。
2. 插针导轨完成后，进罐导轨从当前位置向后移动 220 mm。

屏幕会依次显示“插针后退120mm”和“进罐后退220mm”。

这是一组固定距离的后退动作，不是自动寻找零点。执行前必须确认后方有足够空间，不得将该功能当作开机回零使用。

需要立即停止时按【故障】或【复位】。

### 7. 调试动作进行中

导轨或定量泵动作进行中，屏幕显示当前动作和“请等待”。此时其他动作按键不会生效。

- 等待动作完成后，页面自动恢复到调试主页。
- 按【故障】或【复位】可以停止并退出调试。

### 8. 动作失败

如果屏幕显示“动作失败”：

1. 按【故障】或【复位】退出调试。
2. 检查设备供电、通信线、驱动器、机构阻挡和泵的状态。
3. 排除问题后重新进入调试，不要在失败页面连续重复按键。

### 9. 退出调试

- 按【故障】：停止调试动作并返回待机页面。
- 按【复位】：停止调试动作并返回待机页面。

## 十一、报警页面

当前软件保留以下报警页面：

```text
! 系统严重报警 !
故障:导轨未到位
泵阀已安全锁定
按【复位】清报警
```

当前正常键盘流程不会主动进入该页面。如果现场出现此页面：

1. 确认人员、机构和管路处于安全状态。
2. 在本机控制状态下按【复位】尝试返回待机。
3. 无法恢复或重复出现时，停止使用并检查导轨、泵阀和连接状态。

## 十二、常见问题

### 1. 按键没有反应

- 松开全部按键，再单独短按一次。
- 检查当前页面是否支持该按键。
- 检查设备是否处于远控状态。
- 检查是否有动作正在执行。
- 四个未使用位置按下没有反应属于正常现象。

### 2. 远控页面按复位不能回到待机

先按【暂停】，等待“远控本地暂停”，再按【复位】。

### 3. 按故障键不能进入调试

先切换到本机待机，并等待导轨和两台定量泵完全停止。设备不空闲时不会进入调试。

### 4. 输入错误

- 按【清除】清空整项后重新输入。
- 发药提示超过余量时，重新输入不大于屏幕剩余体积的数值。

### 5. 流程长时间停在“请等待”

先观察当前运动是否仍在进行。确认明显异常时按【暂停】；需要终止时按【复位】，然后检查屏幕提示、机构阻挡、管路和设备连接。

## 十三、安全注意事项

- 调试导轨前，确认导轨运动范围内没有人员、工具、线缆或其他阻挡物。
- 调试泵、执行排气或清空前，确认管路连接正确，并准备好液源和接液容器。
- 【定量排气】和待机页面的【清空】没有第二次确认，准备完成前不要按下。
- 不要用连续点动或固定退轨代替正常的开机回零。
- 发生机械碰撞、液体泄漏或人员安全风险时，立即按照现场紧急停机规程处理。矩阵键盘不能替代独立的安全停机装置。
