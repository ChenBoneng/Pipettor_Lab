# LCD 按键使用说明

本文按当前 `MachineCMD` UI 代码整理，用来说明 12864B LCD 页面、按键入口和页面切换关系。

注意：LCD 使用 ST7920 12864 文本模式，单行最多 16 字节。代码里的中文固定文案必须继续放在 `MachineCMD_Text.c` 的 GB2312 字节表中，不要在 C 字符串里直接写 UTF-8 中文。

## 1. 当前设计原则

- LCD 只显示状态、步骤、短提示和操作选择。
- 本机 UI 只负责切页面和记录操作员意图。
- 当前配药、发药、排气、冲洗等新 UI 不直接启动泵、电机或阀。
- 后续真实动作由 `machine` 层通过预留接口接入。

预留接口：

| 接口 | 用途 |
| --- | --- |
| `MachineCMD_ConsumeLocalPrepStartRequested()` | 读取本机配药启动请求，带 1/2 号药瓶量。 |
| `MachineCMD_ConsumeLocalPrepSwitchRequested()` | 读取换罐后继续请求。 |
| `MachineCMD_ConsumeLocalDispenseStartRequested()` | 读取本机发药启动请求。 |
| `MachineCMD_SetPrepRunStage()` | 由后续业务层更新配药运行阶段和进度。 |
| `MachineCMD_SetPrepSwitchTank()` | 由后续业务层切到换罐提示。 |
| `MachineCMD_SetPrepFinished()` | 由后续业务层切到配药完成提示。 |

## 2. 上电启动

上电后先显示开机初始化页，约 2 秒后默认进入上位机远控页。

```text
自动核素分药仪
系统初始化中..
读取EEPROM...
【就绪】
```

当前设备默认面向上位机使用，因此启动完成后不会直接进入待机页。

## 3. 远控页

启动完成后默认进入远控页。待机页也可以按【远控】重新申请交给上位机。

常见显示：

```text
--上位机远控--
PC控制中...
暂停键挂起
请先按暂停键
```

远控页按键：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 停止当前远控输出，保持远控模式，进入远控本地暂停状态。 |
| 【启动】 | 仅在远控暂停后允许继续接收上位机命令。 |
| 【复位】 | 在 REMOTE/REMOTE_SWITCHING 下不会直接抢回本地控制权；需要先暂停。 |

说明：远控相关动作仍可能调用底层停机或远控执行函数，这是原有远控逻辑，不属于本次本机 UI 新流程。

## 4. 待机页

待机页当前显示：

```text
设备待机
活度 12.5mCi
体积 35.0ml
配药／发药
```

待机页按键入口：

| 按键 | 进入页面 | 说明 |
| --- | --- | --- |
| 【配药】 | 配药设置页 | 选择 1 瓶或 2 瓶，并输入药瓶量。 |
| 【发药】 | 发药设置页 | 输入发药体积；当前只记录 UI 请求。 |
| 【清空】 | 管路冲洗页 | 显示管路冲洗 UI，不直接启动泵。 |
| 【定量排气】 | 自动排气页 | 显示泵2排气 UI，不直接启动泵。 |
| 【故障】 | 报警页 | 显示固定报警提示。 |
| 【远控】 | 远控页 | 申请交给上位机。 |
| 【进罐】【出罐】【插针】【收针】【抽药】 | 手动控制页 | 只显示对应动作名；不新增自动流程。 |
| 数字【1】【2】【4】【5】 | 手动控制页 | 翻转水进、药进、水出、药出开关。 |

## 5. 配药设置页

待机页按【配药】进入。

第一步选择药瓶数：

```text
选择药瓶数
一瓶
二瓶
按1/2
```

按【1】选择一瓶，按【2】选择两瓶。当前最多 2 瓶，没有 3 瓶页面。

输入药量页面：

```text
输入药量
一号:0.0ml

启动确认
```

如果选择 2 瓶，确认 1 号后进入 2 号输入：

```text
输入药量
二号:0.0ml

启动确认
```

输入规则：

| 按键 | 动作 |
| --- | --- |
| 数字【0】~【9】 | 追加到当前药瓶量输入。 |
| 【.】 | 输入小数点；首位输入时自动补成 `0.`。 |
| 【清除】 | 输入框有内容时清空；无内容时退回上一步或退回瓶数选择。 |
| 【启动】 | 保存当前药瓶量；最后一瓶确认后进入配药准备页。 |
| 【复位】 | 放弃本次 UI 输入，返回待机页。 |

说明：药瓶量按 `0.01ml` 存储。空输入确认时按 `0.0ml` 处理。

## 6. 配药准备页

药量输入完成后进入准备确认页：

```text
开始配药
放入一号罐
准备水和杯
启动继续
```

按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 记录 `prep_start_requested`，并切到自动配药 UI 阶段。 |
| 【复位】 | 显示“正在中止”收尾提示。 |

当前【启动】只记录请求，不直接启动机械动作。

## 7. 自动配药页

配药准备页按【启动】后进入自动配药 UI。默认先显示进罐阶段：

```text
自动配药
步骤1
进罐运行
请等待
```

后续业务层可以通过 `MachineCMD_SetPrepRunStage()` 切换阶段：

| 阶段 | LCD 显示 |
| --- | --- |
| `IN_TANK` | 步骤1 / 进罐运行 / 请等待 |
| `INSERT_NEEDLE` | 步骤2 / 插针运行 / 请等待 |
| `DRAW_WATER` | 步骤3 / 抽水中 / 请等待 |
| `WATER_FILL` | 步骤4 / 补水中 / `已完成/总量ml` |
| `ACTIVITY_CHECK` | 切到活度检测页 |
| `SWITCH_TANK` | 切到换罐提示 |
| `EXHAUST` | 切到自动排气页 |
| `FLUSH` | 切到管路冲洗页 |
| `DONE` | 切到配药完成页 |
| `ABORTING` | 切到正在中止页 |

自动配药页按键：

| 按键 | 动作 |
| --- | --- |
| 【发药】 | 只有配药完成阶段允许进入发药设置页。 |
| 【暂停】 | 进入流程暂停页。 |
| 【复位】 | 显示“正在中止”，并置位原有复位事件供业务层收尾。 |

## 8. 活度检测页

业务层设置 `MACHINE_CMD_PREP_RUN_STAGE_ACTIVITY_CHECK` 后进入。

倒计时中显示：

```text
活度检测
稳定读数
剩余:15s
请等待
```

倒计时结束后显示检测完成：

```text
检测完成
活度:12.5mCi
计算中

```

当前倒计时仍为 15 秒。倒计时结束后 UI 会切到配药完成页。

## 9. 换罐页

后续业务层调用 `MachineCMD_SetPrepSwitchTank(1, 2)` 后显示：

```text
一号完成
请换药罐
放入二号
启动继／复位停
```

按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 记录换罐继续请求，并切回自动配药 UI。 |
| 【复位】 | 显示“正在中止”，后续应由业务层执行冲洗、复位等收尾。 |

当前项目最多 2 瓶，因此不会显示“放入3号”。

## 10. 自动排气页

待机页按【定量排气】进入，或后续业务层设置 `EXHAUST` 阶段进入。

```text
自动排气
泵二运行
请等待

```

当前只显示 UI，不直接启动泵2。

## 11. 管路冲洗页

待机页按【清空】进入，或后续业务层设置 `FLUSH` 阶段进入。

```text
管路冲洗
泵一运行
进度:0%
请等待
```

当前只显示 UI，不直接启动泵1。后续业务层可通过 `MachineCMD_SetPrepRunStage(FLUSH, done, total)` 更新进度。

## 12. 配药完成页

后续业务层调用 `MachineCMD_SetPrepFinished()`，或活度检测倒计时结束后进入。

```text
配药完成
浓度:0.125mCi
等待发药

```

按键：

| 按键 | 动作 |
| --- | --- |
| 【发药】 | 进入发药设置页。 |
| 【启动】 | 返回待机页。 |
| 【复位】 | 返回待机页。 |

说明：当前完成页浓度显示值来自 UI 接口参数或待机浓度缓存，真实浓度后续由业务层接入。

## 13. 发药设置页

待机页按【发药】进入。配药完成页按【发药】也可进入。

```text
发药设置
剩余:35.0ml
输入:0.0ml
启动开始
```

输入规则：

| 按键 | 动作 |
| --- | --- |
| 数字【0】~【9】 | 追加发药体积。 |
| 【.】 | 输入小数点。 |
| 【清除】 | 清空输入。 |
| 【启动】 | 校验不超过剩余体积；通过后记录发药请求并进入发药运行页。 |
| 【复位】 | 返回待机页。 |

如果输入体积大于剩余体积，第 4 行显示：

```text
输入超过余量
```

当前【启动】只记录 `dispense_start_requested`，不会直接启动泵2。

## 14. 发药运行页

发药设置页按【启动】并通过余量校验后进入。

```text
正在发药
泵二运行
完成:0%

```

当前只显示 UI。进度仍读取 `Machine_GetDispenseProgressPercent()`，后续真实发药流程接入后会自动反映业务层进度。

按键：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 进入流程暂停页。 |
| 【复位】 | 显示“正在中止”，并置位原有复位事件。 |

## 15. 正在中止页

运行类页面按【复位】后进入。

```text
正在中止
管路冲洗
导轨复位
请等待
```

当前页面只提示中止收尾。真实冲洗、导轨复位等动作应由后续 `machine` 层接入。

## 16. 流程暂停页

配药运行、活度检测、发药运行页按【暂停】进入。

```text
! 流程已暂停 !
配药流程中断
启动键继续
复位键终止
```

如果从发药运行页暂停，第 2 行显示“发药流程中断”。

按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 返回暂停前页面。 |
| 【复位】 | 置位复位事件并进入中止/待机逻辑。 |

注意：暂停函数沿用原逻辑，会停止已知执行器输出。

## 17. 手动控制页

待机页按【进罐】【出罐】【插针】【收针】【抽药】，或按数字【1】【2】【4】【5】进入。

```text
--手动控制模式--
水进:关药进:关
水出:关药出:关
按1245切换
```

手动页按键：

| 按键 | 动作 |
| --- | --- |
| 【1】 | 翻转水进开关。 |
| 【2】 | 翻转药进开关。 |
| 【4】 | 翻转水出开关。 |
| 【5】 | 翻转药出开关。 |
| 【进罐】【出罐】【插针】【收针】【抽药】 | 只更新第 4 行动作名称。 |
| 【复位】 | 关闭手动输出并返回待机页。 |

手动页是旧调试入口，仍会通过 `MachineCMD_ApplyManualOutputs()` 控制阀和抽水泵。

## 18. 报警页

待机页按【故障】进入。

```text
! 系统严重报警 !
故障:导轨未到位
泵阀已安全锁定
按【复位】清报警
```

按【复位】返回待机页。当前报警内容仍是固定文案。

## 19. 当前本机 UI 流程

```text
上电
  ↓
初始化
  ↓
远控页
  ↓
待机
  ↓
选择任务

配药：
选择瓶数 -> 输入1号药量 -> 输入2号药量(可选)
-> 准备确认 -> 自动配药 -> 换罐(可选)
-> 活度检测 -> 排气/冲洗(后续接入) -> 配药完成

发药：
发药设置 -> 正在发药
```

要点：当前说明对应的是 UI 层状态壳。除远控和手动调试旧逻辑外，新配药/发药/排气/冲洗页面只记录请求和显示阶段，不直接执行硬件动作。
