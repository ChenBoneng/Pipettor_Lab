# LCD 按键使用说明

本文按当前 `MachineCMD`、`Keyboard` 和 `MachineCMD_Text` 的实际代码重新整理，用来说明上电后的 LCD 页面、按键入口和页面变化。

> 说明：LCD 使用 ST7920 文本模式。程序里的中文文案按 GB2312 字节表发送，本文直接写中文，方便查看。

## 1. 上电启动

系统上电后，`MachineCMD_Init()` 先进入开机初始化页，保持约 2 秒。

LCD 显示：

```text
自动核素分药仪
系统初始化中..
读取EEPROM...
【就绪】
```

2 秒后自动进入启动就绪页。

LCD 显示：

```text
自动核素分药仪
系统启动就绪
按任意按键启动

```

启动就绪页按任意按键后进入待机页。这个按键只用于确认启动，不会继续执行按键本身的功能。

## 2. 通用复位逻辑

除启动就绪页外，按【复位】会执行统一退出逻辑：

- 清空当前数字输入；
- 关闭手动调试输出；
- 返回待机页。

如果在暂停页按【复位】，表示终止当前提示流程并回到待机页。

## 3. 待机页

待机页是默认主页面，用于显示设备基础信息。

LCD 显示：

```text
状态:待机中
浓度:000.0mCi/ml
余量:000.0mCi
体积:000.0ml
```

当前浓度、余量、体积还是固定占位值，后续接入活度计和业务状态后再替换为实时数据。

待机页按键入口：

| 按键 | 进入页面 | 说明 |
| --- | --- | --- |
| 【配药】 | 配药量设置页 | 输入瓶 1、瓶 2、瓶 3 配药量 |
| 【发药】 | 发药量设置页 | 输入目标发药体积 |
| 【清空】 | 自动清洗页 | 显示管路冲洗排空提示 |
| 【故障】 | 报警页 | 显示当前预留报警页面 |
| 【进罐】 | 手动控制页 | 最后动作显示“进罐导轨” |
| 【出罐】 | 手动控制页 | 最后动作显示“出罐导轨” |
| 【插针】 | 手动控制页 | 最后动作显示“插针” |
| 【收针】 | 手动控制页 | 最后动作显示“收针” |
| 【抽药】 | 手动控制页 | 最后动作显示“抽药” |
| 【定量排气】 | 手动控制页 | 最后动作显示“定量排气” |
| 【远控】 | 手动控制页 | 最后动作显示“上位机远控” |
| 【1】【2】【4】【5】 | 手动控制页 | 直接翻转水进、药进、水出、药出开关 |

## 4. 配药量设置页

在待机页按【配药】进入。

LCD 显示：

```text
《配药量设置》
瓶1:__ 瓶2:__
瓶3:__ml
按【启动】键开始
```

配药输入逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到当前瓶号输入框 |
| 【.】 | 输入小数点；如果第一个按下，会自动补成 `0.` |
| 【清除】 | 清空当前瓶号输入框 |
| 【启动】 | 保存当前瓶号输入，并进入下一瓶 |
| 【复位】 | 放弃当前输入，返回待机页 |

输入顺序：

1. 先输入瓶 1；
2. 按【启动】保存瓶 1，进入瓶 2；
3. 再按【启动】保存瓶 2，进入瓶 3；
4. 第三次按【启动】保存瓶 3，进入配药运行提示页。

当前输入最多 5 个字符，例如 `99.99`。数值在程序中按 `0.01 ml` 存储，例如输入 `2.50`，内部保存为 `250`。

## 5. 配药运行提示页

配药量设置页完成 3 个瓶号输入后进入。

LCD 显示：

```text
配药中：正在进罐
进罐导轨
请放入一号铅罐
按【启动】键确认
```

配药运行提示页按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 进入活度计测量页 |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

当前这一页主要负责 LCD 提示，真实进罐动作后续应由 `machine` 层状态机接管。

## 6. 活度计测量页

在配药运行提示页按【启动】后进入。该页会显示 15 秒倒计时，倒计时结束后自动回到待机页。

LCD 显示：

```text
配药中:测量活度
请等待活度计稳定
倒计时:15s
[暂停]挂起流程
```

活度计测量页按键：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

如果从暂停页按【启动】恢复到测量页，当前代码会重新开始 15 秒倒计时。

## 7. 发药量设置页

在待机页按【发药】进入。

LCD 显示：

```text
《发药量设置》
目标:____ml

按【启动】键开始
```

发药输入逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到目标体积输入框 |
| 【.】 | 输入小数点；如果第一个按下，会自动补成 `0.` |
| 【清除】 | 清空目标体积输入框 |
| 【启动】 | 保存目标体积，进入发药运行提示页 |
| 【复位】 | 放弃当前输入，返回待机页 |

## 8. 发药运行提示页

发药量设置页按【启动】后进入。

LCD 显示：

```text
发药执行中...
泵二正在发药
完成进度：000%
[暂停]挂起流程
```

发药运行提示页按键：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

当前完成进度仍是固定占位 `000%`，真实泵运行和进度刷新后续应由业务流程接入。

## 9. 流程暂停页

配药运行页、活度计测量页、发药运行页按【暂停】后进入。

LCD 显示：

```text
! 流程已暂停 !
当前:配药中断
按[启动]键继续
按[复位]键终止
```

如果从发药运行页暂停，第 2 行显示：

```text
当前:发药中断
```

暂停页按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 返回暂停前的运行提示页 |
| 【复位】 | 终止当前提示流程，返回待机页 |

当前暂停动作会调用 `StepMotor_StopAll()`，并关闭 `MachineCMD` 管理的手动阀泵输出。ISC1000 定量泵的真实暂停还需要后续在 `machine` 层统一接管。

## 10. 手动控制页

在待机页按动作键，或直接按数字【1】【2】【4】【5】进入。

LCD 显示示例：

```text
--手动控制模式--
最后:进罐导轨
1关 2关 4关 5关
按[复位]退出手动
```

如果按数字键进入或在手动页按数字键，第 2 行会显示最后操作对象及开关状态，例如：

```text
最后:水进开
```

手动控制页按键：

| 按键 | 手动功能 | 当前硬件映射 |
| --- | --- | --- |
| 【1】 | 水进开关翻转 | 阀 1 |
| 【2】 | 药进开关翻转 | 阀 2 |
| 【4】 | 水出开关翻转 | 阀 1 + 抽水泵 |
| 【5】 | 药出开关翻转 | 阀 2 + 抽水泵 |
| 【进罐】 | 更新最后动作 | 显示“进罐导轨” |
| 【出罐】 | 更新最后动作 | 显示“出罐导轨” |
| 【插针】 | 更新最后动作 | 显示“插针” |
| 【收针】 | 更新最后动作 | 显示“收针” |
| 【抽药】 | 更新最后动作 | 显示“抽药” |
| 【定量排气】 | 更新最后动作 | 显示“定量排气” |
| 【远控】 | 更新最后动作 | 显示“上位机远控” |
| 【复位】 | 退出手动页 | 关闭所有手动输出并返回待机页 |

注意：

- 数字键在手动控制页不作为数值输入；
- 每按一次【1】、【2】、【4】、【5】，对应开关翻转一次；
- 其它动作键目前只更新 LCD 的“最后”动作提示；
- 真正的导轨、插针、抽药动作后续建议由 `machine` 层接管。

## 11. 自动清洗页

在待机页按【清空】进入。

LCD 显示：

```text
<<自动清洗>>
冲洗管道排空...
泵一正在运行
请放置废液杯!
```

当前 `MachineCMD` 只显示自动清洗提示，还没有在本模块内真正启动泵 1。实际冲洗动作后续应由 `machine` 层执行。

自动清洗页按键：

| 按键 | 动作 |
| --- | --- |
| 【复位】 | 退出并返回待机页 |

## 12. 报警页

在待机页按【故障】进入，后续真实报警也可以统一切到该页。

LCD 显示：

```text
! 系统严重报警 !
故障：导轨未到位
泵阀已安全锁定
按【复位】清报警
```

报警页按键：

| 按键 | 动作 |
| --- | --- |
| 【复位】 | 清除当前 UI 报警提示，返回待机页 |

当前报警内容还是固定文案，真实故障源后续需要接入通信超时、导轨未到位、活度计读取失败等状态。

## 13. 远控说明

当前【远控】键只进入手动控制页，并把最后动作显示为“上位机远控”。

这说明程序已经给远控状态预留了 UI 入口，但还没有真正让上位机接管设备。后续扩展时，建议仍由 `Communication` 负责接收 CAN 指令，`machine` 层负责执行动作，`MachineCMD` 只负责显示当前状态。

## 14. 当前按键功能总表

| 按键功能 | 当前用途 |
| --- | --- |
| 【配药】 | 待机页进入配药量设置页 |
| 【发药】 | 待机页进入发药量设置页 |
| 【清空】 | 待机页进入自动清洗页 |
| 【故障】 | 待机页进入报警页 |
| 【进罐】 | 待机页进入手动控制页，显示进罐导轨 |
| 【出罐】 | 待机页进入手动控制页，显示出罐导轨 |
| 【插针】 | 待机页进入手动控制页，显示插针 |
| 【收针】 | 待机页进入手动控制页，显示收针 |
| 【抽药】 | 待机页进入手动控制页，显示抽药 |
| 【定量排气】 | 待机页进入手动控制页，显示定量排气 |
| 【远控】 | 待机页进入手动控制页，显示上位机远控 |
| 【启动】 | 启动就绪页确认启动；设置页确认输入；运行页进入下一提示页；暂停页继续 |
| 【暂停】 | 配药运行、测量、发药运行页进入暂停页 |
| 【清除】 | 配药/发药设置页清空当前输入 |
| 【复位】 | 退出当前页面，关闭手动输出，返回待机页 |
| 数字键【0】~【9】 | 配药/发药设置页作为数值输入 |
| 数字键【1】【2】【4】【5】 | 待机页或手动控制页作为水进、药进、水出、药出开关 |
| 【.】 | 配药/发药设置页输入小数点 |

## 15. 简单操作流程

配药流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按【配药】 -> 输入瓶1 -> 按【启动】
     -> 输入瓶2 -> 按【启动】
     -> 输入瓶3 -> 按【启动】
     -> 配药运行提示页 -> 按【启动】
     -> 活度计测量页 15 秒 -> 自动回待机页
```

发药流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按【发药】 -> 输入目标体积 -> 按【启动】
     -> 发药运行提示页
```

手动控制流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按动作键或【1】【2】【4】【5】进入手动控制页
     -> 按【1】【2】【4】【5】控制阀/泵开关
     -> 按【复位】关闭输出并返回待机页
```

清洗流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按【清空】 -> 自动清洗提示页
     -> 按【复位】返回待机页
```
