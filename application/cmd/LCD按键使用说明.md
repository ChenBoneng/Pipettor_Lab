# LCD 按键使用说明

本文按当前 `MachineCMD`、`Keyboard` 和 LCD 文案表的实现编写，用来说明上电后 LCD 显示内容、按键进入的状态，以及每个状态下按键带来的变化。

> 说明：当前 LCD 使用 ST7920 文本模式。中文文案实际在程序里按 GB2312 字节表发送，本文直接写成中文，方便查看。

## 1. 上电启动

系统上电后，`MachineCMD_Init()` 会先进入开机页。

LCD 显示：

```text
自动核素分药仪
系统初始化中..
读取EEPROM...
[就绪]
```

当前代码中，开机页保持约 1 秒，之后自动进入待机页。

如果在任意页面按下【复位】键，会执行统一退出逻辑：

- 清空当前数字输入；
- 关闭手动调试输出；
- 返回待机页。

## 2. 待机页

待机页是默认主页面，用于显示设备当前基础信息。

LCD 显示：

```text
状态:待机中
浓度:000.0mCi/L
余量:000.0mCi
体积:000.0ml
```

当前浓度、余量、体积还是固定占位值，后续接入活度计和业务状态后，再替换为实时数据。

待机页按键变化：

| 按键 | 进入状态 | LCD 变化 |
| --- | --- | --- |
| 【配药】 | 配药量设置页 | 显示瓶号输入 |
| 【发药】 | 发药量设置页 | 显示目标体积输入 |
| 【进罐】 | 手动调试页 | 当前动作显示“进罐导轨” |
| 【出罐】 | 手动调试页 | 当前动作显示“出罐导轨” |
| 【插针】 | 手动调试页 | 当前动作显示“插针” |
| 【收针】 | 手动调试页 | 当前动作显示“收针” |
| 【抽药】 | 手动调试页 | 当前动作显示“抽药” |
| 【定量排气】 | 手动调试页 | 当前动作显示“定量排气” |
| 【远控】 | 手动调试页 | 当前动作显示“上位机远控” |

## 3. 配药量设置页

在待机页按【配药】进入。

LCD 显示：

```text
<< 配药量设置 >>
瓶1:__ml
已存:0/0
按[启动]键开始
```

配药输入逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到当前瓶号输入框 |
| 【.】 | 输入小数点；不能作为第一个字符，也不能重复输入 |
| 【清除】 | 清空当前输入框 |
| 【启动】 | 保存当前瓶号输入，并进入下一瓶 |
| 【复位】 | 放弃当前输入，返回待机页 |

输入顺序：

1. 第一次输入的是瓶 1 的配药量；
2. 按【启动】后保存瓶 1，进入瓶 2；
3. 再按【启动】后保存瓶 2，进入瓶 3；
4. 第三次按【启动】后保存瓶 3，进入配药运行提示页。

数值在程序中按 `0.01 ml` 存储，例如输入 `2.50`，内部保存为 `250`。

## 4. 配药运行提示页

配药量设置页完成 3 个瓶号输入后进入。

LCD 显示：

```text
配药中:正在进罐

请放入1号铅罐!
按[启动]键确认
```

当前代码中，这一页只做 LCD 提示，还没有接入真正的配药流程状态机。

也就是说：

- LCD 会显示“按[启动]键确认”；
- 但当前 `MachineCMD_Process()` 暂时没有处理运行页里的【启动】；
- 需要后续由 `machine` 层接管配药动作后，再让【启动】继续推进流程；
- 目前可以按【复位】返回待机页。

## 5. 发药量设置页

在待机页按【发药】进入。

LCD 显示：

```text
<< 发药量设置 >>
目标:____ml

按[启动]键开始
```

发药输入逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到目标体积输入框 |
| 【.】 | 输入小数点；不能作为第一个字符，也不能重复输入 |
| 【清除】 | 清空当前输入框 |
| 【启动】 | 保存目标体积，进入发药运行提示页 |
| 【复位】 | 放弃当前输入，返回待机页 |

## 6. 发药运行提示页

发药量设置页按【启动】后进入。

LCD 显示：

```text
发药执行中...
泵2正在发药
完成进度:000%
切勿移开药瓶!
```

当前代码中，这一页也是运行提示页，暂时显示固定进度占位 `000%`。

目前可以按【复位】返回待机页。真正的泵运行进度需要后续接入业务流程后再刷新。

## 7. 手动调试页

在待机页按动作类按键进入，例如【进罐】、【出罐】、【插针】、【抽药】、【远控】等。

LCD 显示：

```text
手动调试模式
当前: 进罐导轨
1水进 2药进
4水出 5药出
```

第 2 行会根据进入时的动作键变化，例如：

- 按【进罐】进入，显示 `当前: 进罐导轨`；
- 按【出罐】进入，显示 `当前: 出罐导轨`；
- 按【插针】进入，显示 `当前: 插针`；
- 按【收针】进入，显示 `当前: 收针`；
- 按【抽药】进入，显示 `当前: 抽药`；
- 按【定量排气】进入，显示 `当前: 定量排气`；
- 按【远控】进入，显示 `当前: 上位机远控`。

手动调试页数字键复用：

| 按键 | 手动功能 | 当前硬件映射 |
| --- | --- | --- |
| 【1】 | 水进开关翻转 | 打开/关闭阀 1 |
| 【2】 | 药进开关翻转 | 打开/关闭阀 2 |
| 【4】 | 水出开关翻转 | 打开/关闭阀 1，同时控制抽水泵 |
| 【5】 | 药出开关翻转 | 打开/关闭阀 2，同时控制抽水泵 |

注意：

- 数字键在手动调试页不作为数值输入；
- 每按一次【1】、【2】、【4】、【5】，对应开关会翻转一次；
- 其它动作键在手动调试页只更新第 2 行“当前:”提示；
- 按【复位】会关闭所有手动输出，并返回待机页。

## 8. 远控状态

当前【远控】键的实现是进入手动调试页，并把当前动作显示为：

```text
当前: 上位机远控
```

当前框架已经把远控作为一个独立动作状态保留下来，但还没有真正接入上位机命令接管逻辑。

后续如果要让上位机发送配药、发药、手动阀泵控制等指令，建议在这个状态下增加通信命令入口，而不要把上位机命令直接塞进 LCD 显示函数里。

## 9. 报警页

报警页文案已经预留。

LCD 显示：

```text
! 系统严重报警 !
故障:导轨未到位
泵阀已安全锁定
按[复位]清除报警
```

当前代码中还没有真实报警源，也没有从按键直接进入报警页的入口。

后续接入通信超时、导轨未到位、活度计读取失败等故障后，可以统一切到报警页。报警页中按【复位】返回待机页。

## 10. 当前按键功能表

| 按键功能 | 当前用途 |
| --- | --- |
| 【配药】 | 待机页进入配药量设置页 |
| 【发药】 | 待机页进入发药量设置页 |
| 【进罐】 | 待机页进入手动调试页，显示进罐导轨 |
| 【出罐】 | 待机页进入手动调试页，显示出罐导轨 |
| 【插针】 | 待机页进入手动调试页，显示插针 |
| 【收针】 | 待机页进入手动调试页，显示收针 |
| 【抽药】 | 待机页进入手动调试页，显示抽药 |
| 【定量排气】 | 待机页进入手动调试页，显示定量排气 |
| 【远控】 | 待机页进入手动调试页，显示上位机远控 |
| 【启动】 | 在配药/发药设置页确认当前输入 |
| 【清除】 | 在配药/发药设置页清空当前输入 |
| 【复位】 | 任意页面返回待机页，并关闭手动输出 |
| 数字键【0】~【9】 | 配药/发药设置页作为数值输入 |
| 数字键【1】【2】【4】【5】 | 手动调试页作为水进、药进、水出、药出开关 |

| 【故障】 | 当前 `MachineCMD` 暂未处理 |
| 【清空】 | 当前 `MachineCMD` 暂未处理 |
| 【暂停】 | 当前 `MachineCMD` 暂未处理 |

## 11. 简单操作流程

配药流程：

```text
上电 -> 待机页 -> 按【配药】 -> 输入瓶1 -> 按【启动】
                 -> 输入瓶2 -> 按【启动】
                 -> 输入瓶3 -> 按【启动】
                 -> 配药运行提示页
```

发药流程：

```text
上电 -> 待机页 -> 按【发药】 -> 输入目标体积 -> 按【启动】 -> 发药运行提示页
```

手动调试流程：

```text
上电 -> 待机页 -> 按动作键进入手动调试页
                 -> 按【1】【2】【4】【5】控制阀/泵开关
                 -> 按【复位】关闭输出并返回待机页
```
