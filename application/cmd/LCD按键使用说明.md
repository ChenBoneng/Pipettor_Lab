# LCD 按键使用说明

本文按当前 `MachineCMD` 与 `machine` 流程代码整理，用来说明 12864B LCD 页面、按键入口和本机动作关系。

注意：LCD 使用 ST7920 12864 文本模式，单行最多 16 字节。代码里的中文固定文案必须继续放在 `MachineCMD_Text.c` 的 GB2312 字节表中，不要在 C 字符串里直接写 UTF-8 中文。

## 1. 当前设计原则

- LCD 只显示状态、步骤、短提示和操作选择，不显示长说明文字。
- `MachineCMD` 负责页面切换、输入缓存和操作请求置位。
- `MachineControl()` 负责消费本机请求，并启动配药、发药、排气、冲洗等真实流程。
- 本机配药最多支持 2 瓶，没有 3 瓶页面。
- 配药完成后会自动执行排气和冲洗；单独排气、单独清空/冲洗从待机页独立启动。

主要接口：

| 接口 | 用途 |
| --- | --- |
| `MachineCMD_ConsumeLocalPrepStartRequested()` | 读取本机配药启动请求，带 1/2 号药瓶量。 |
| `MachineCMD_ConsumeLocalPrepSwitchRequested()` | 读取换罐后继续请求。 |
| `MachineCMD_ConsumeLocalDispenseStartRequested()` | 读取本机发药启动请求。 |
| `MachineCMD_ConsumeLocalExhaustRequested()` | 读取本机单独排气请求。 |
| `MachineCMD_ConsumeLocalEmptyRequested()` | 读取本机单独清空/冲洗请求。 |
| `MachineCMD_SetPrepRunStage()` | 由 `machine` 层更新配药、排气、冲洗阶段和进度。 |
| `MachineCMD_SetPrepSwitchTank()` | 由 `machine` 层切到换罐提示。 |
| `MachineCMD_SetPrepFinished()` | 由 `machine` 层切到配药完成提示。 |

## 2. 上电启动

上电后先显示开机初始化页，约 2 秒后默认进入上位机远控页。

```text
自动核素分药仪
系统初始化中..
读取EEPROM...
【就绪】
```

当前设备默认面向上位机使用，因此启动完成后不会直接进入待机页。

## 3. 远控页

启动完成后默认进入远控页。待机页也可以按【远控】重新申请交给上位机。

常见显示：

```text
--上位机远控--
PC控制中...
暂停键挂起
请先按暂停键
```

远控页按键：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 停止当前远控输出，保持远控模式，进入远控本地暂停状态。 |
| 【启动】 | 远控暂停后恢复接收上位机命令。 |
| 【复位】 | 在 REMOTE/REMOTE_SWITCHING 下不会直接抢回本地控制权，需要先暂停。 |

说明：上位机发送 `STOP_PROCESS` 时，会先切断当前输出，再置位复位请求，由 `MachineControl()` 统一中止整个自动流程。

## 4. 待机页

待机页当前显示：

```text
设备待机
活度 12.5mCi
体积 35.0ml
配药／发药
```

待机页按键入口：

| 按键 | 进入页面 | 实际动作 |
| --- | --- | --- |
| 【配药】 | 配药设置页 | 选择 1 瓶或 2 瓶，并输入药瓶量。 |
| 【发药】 | 发药设置页 | 输入发药体积，启动后由 `machine` 层执行泵2发药。 |
| 【清空】 | 管路冲洗页 | 置位 `empty_requested`，由 `machine` 层执行本机单独清空/冲洗。 |
| 【定量排气】 | 自动排气页 | 置位 `exhaust_requested`，由 `machine` 层执行本机单独排气。 |
| 【故障】 | 报警页 | 显示固定报警提示。 |
| 【远控】 | 远控页 | 申请交给上位机控制。 |
| 【进罐】【出罐】【插针】【收针】【抽药】 | 手动控制页 | 显示对应手动动作名。 |
| 数字【1】【2】【4】【5】 | 手动控制页 | 翻转水进、药进、水出、药出开关。 |

## 5. 配药设置页

待机页按【配药】进入。

第一步选择药瓶数：

```text
选择药瓶数
一瓶
两瓶
按1/2
```

按【1】选择一瓶，按【2】选择两瓶。当前最多 2 瓶，没有 3 瓶页面。

输入药量页面：

```text
输入药量
一号:0.0ml

启动确认
```

如果选择 2 瓶，确认 1 号后进入 2 号输入：

```text
输入药量
二号:0.0ml

启动确认
```

输入规则：

| 按键 | 动作 |
| --- | --- |
| 数字【0】~【9】 | 追加到当前药瓶量输入。 |
| 【.】 | 输入小数点；首位输入时自动补成 `0.`。 |
| 【清除】 | 输入框有内容时清空；无内容时退回上一步或退回瓶数选择。 |
| 【启动】 | 保存当前药瓶量；最后一瓶确认后进入配药准备页。 |
| 【复位】 | 放弃本次输入，返回待机页。 |

说明：药瓶量按 `0.01ml` 存储。未输入时界面显示 `0.0ml`，方便操作员确认当前输入值。

## 6. 配药准备页

药量输入完成后进入准备确认页：

```text
开始配药
放入一号罐
准备水和杯
启动继续
```

按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 置位 `prep_start_requested`，`MachineControl()` 随后启动本机配药流程。 |
| 【复位】 | 切到“正在中止”提示，并置位复位请求。 |

本机配药启动后，`machine` 层会调用 `Machine_StartLocalPrepare()`，进入完整自动配药流程。

## 7. 自动配药页

配药准备页按【启动】后进入自动配药 UI。流程由 `machine` 层推进，页面随阶段刷新。

典型进罐阶段：

```text
自动配药
步骤1
进罐运行
请等待
```

当前阶段显示：

| 阶段 | LCD 显示 | 说明 |
| --- | --- | --- |
| `READY` | 开始配药 / 放入一号罐 / 准备水和杯 / 启动继续 | 准备确认。 |
| `IN_TANK` | 步骤1 / 进罐运行 / 请等待 | 进罐导轨到位。 |
| `INSERT_NEEDLE` | 步骤2 / 插针运行 / 请等待 | 插针导轨到位。 |
| `DRAW_WATER` | 步骤3 / 抽水中 / 请等待 | 抽水泵抽取药瓶液体。 |
| `WATER_FILL` | 步骤4 / 补水中 / `已完成/总量ml` | 泵1按分段量补水。 |
| `ACTIVITY_CHECK` | 活度检测页 | 活度计稳定读数。 |
| `SWITCH_TANK` | 换罐提示页 | 两瓶配药时，1 号完成后等待换 2 号。 |
| `EXHAUST` | 自动排气页 | 配药完成后自动排气。 |
| `FLUSH` | 管路冲洗页 | 排气后自动冲洗。 |
| `DONE` | 配药完成页 | 流程完成，等待发药。 |
| `ABORTING` | 正在中止页 | 复位或急停后的收尾提示。 |

自动配药页按键：

| 按键 | 动作 |
| --- | --- |
| 【发药】 | 只有配药完成阶段允许进入发药设置页。 |
| 【暂停】 | 进入流程暂停页。 |
| 【复位】 | 置位复位请求，由 `machine` 层中止整体流程。 |

## 8. 活度检测页

`machine` 层进入活度稳定阶段后显示：

```text
活度检测
稳定读数
剩余:15s
请等待
```

检测完成后显示：

```text
检测完成
活度:12.5mCi
计算中

```

当前活度检测等待时间为 15 秒。完成后 `machine` 层继续进入自动排气、自动冲洗，最后进入配药完成页。

## 9. 换罐页

两瓶配药时，1 号完成后显示：

```text
一号完成
请换药罐
放入二号
启动继／复位停
```

按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 置位换罐继续请求，`machine` 层继续执行 2 号药瓶流程。 |
| 【复位】 | 置位复位请求，进入“正在中止”收尾提示。 |

当前项目最多 2 瓶，因此不会显示“放入三号”。

## 10. 自动排气页

待机页按【定量排气】进入，或配药完成检测后由 `machine` 层自动进入。

```text
自动排气
泵二运行
请等待

```

说明：

- 单独按【定量排气】时，`MachineControl()` 会启动本机单独排气流程。
- 配药流程中进入该页时，属于配药后的自动排气。
- 当前排气量由 `MACHINE_EXHAUST_VOLUME_ML_X100` 控制，暂定为 `3.00ml`。
- 单独排气结束后自动返回待机页；配药内排气结束后继续进入冲洗。

## 11. 管路冲洗页

待机页按【清空】进入，或排气后由 `machine` 层自动进入。

```text
管路冲洗
泵一运行
进度:0%
请等待
```

说明：

- 单独按【清空】时，`MachineControl()` 会启动本机单独清空/冲洗流程。
- 配药流程中进入该页时，属于配药后的自动冲洗。
- 发药完成后也会自动执行泵1冲洗。
- 当前冲洗量由 `MACHINE_FLUSH_VOLUME_ML_X100` 控制，暂定为 `3.00ml`。
- 进度来自 `MachineCMD_SetPrepRunStage(FLUSH, done, total)` 或发药进度接口。
- 单独清空/冲洗结束后自动返回待机页。

## 12. 配药完成页

配药、活度检测、排气、冲洗都完成后进入：

```text
配药完成
浓度:0.125mCi
等待发药

```

按键：

| 按键 | 动作 |
| --- | --- |
| 【发药】 | 进入发药设置页。 |
| 【启动】 | 返回待机页。 |
| 【复位】 | 返回待机页。 |

说明：浓度显示来自 `machine` 层计算结果；当前测试阶段活度计容量按 20ml 宏参与浓度换算。

## 13. 发药设置页

待机页按【发药】进入。配药完成页按【发药】也可进入。

```text
发药设置
剩余:35.0ml
输入:0.0ml
启动开始
```

输入规则：

| 按键 | 动作 |
| --- | --- |
| 数字【0】~【9】 | 追加发药体积。 |
| 【.】 | 输入小数点。 |
| 【清除】 | 清空输入。 |
| 【启动】 | 校验不超过剩余体积；通过后置位发药请求并进入发药运行页。 |
| 【复位】 | 返回待机页。 |

如果输入体积大于剩余体积，第 4 行显示：

```text
输入超过余量
```

启动成功后，`MachineControl()` 会调用 `Machine_StartDirectDispense()`，由泵2执行发药。

## 14. 发药运行页

发药设置页按【启动】并通过余量校验后进入。

```text
正在发药
泵二运行
完成:0%

```

说明：

- 发药进度来自 `Machine_GetDispenseProgressPercent()`。
- 泵2发药完成后，`machine` 层会自动执行泵1冲洗。
- 发药和冲洗都完成后返回待机页。

按键：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 进入流程暂停页。 |
| 【复位】 | 置位复位请求，由 `machine` 层中止整体发药流程。 |

## 15. 正在中止页

运行类页面按【复位】，或上位机发送 `STOP_PROCESS` 后进入中止逻辑。

```text
正在中止
管路冲洗
导轨复位
请等待
```

说明：页面提示中止收尾；真实停止当前输出和中止整体流程由 `MachineCMD_StopRemoteOutputs()` 与 `MachineControl()` 协同完成。

## 16. 流程暂停页

配药运行、活度检测、发药运行页按【暂停】进入。

```text
! 流程已暂停 !
配药流程中断
启动键继续
复位键终止
```

如果从发药运行页暂停，第 2 行显示“发药流程中断”。

按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 返回暂停前页面。 |
| 【复位】 | 置位复位请求并进入中止逻辑。 |

注意：暂停函数沿用原逻辑，会停止已知执行器输出。

## 17. 手动控制页

待机页按【进罐】【出罐】【插针】【收针】【抽药】，或按数字【1】【2】【4】【5】进入。

```text
--手动控制模式--
水进:关药进:关
水出:关药出:关
按1245切换
```

手动页按键：

| 按键 | 动作 |
| --- | --- |
| 【1】 | 翻转水进开关。 |
| 【2】 | 翻转药进开关。 |
| 【4】 | 翻转水出开关。 |
| 【5】 | 翻转药出开关。 |
| 【进罐】【出罐】【插针】【收针】【抽药】 | 更新第 4 行动作名称。 |
| 【复位】 | 关闭手动输出并返回待机页。 |

手动页是调试入口，阀和抽水泵输出仍会通过 `MachineCMD_ApplyManualOutputs()` 刷新。

## 18. 报警页

待机页按【故障】进入。

```text
! 系统严重报警 !
故障:导轨未到位
泵阀已安全锁定
按【复位】清报警
```

按【复位】返回待机页。当前报警内容仍是固定文案。

## 19. 当前本机流程

```text
上电
  ↓
初始化
  ↓
远控页
  ↓
待机
  ↓
选择任务

本机配药：
选择瓶数 -> 输入1号药量 -> 输入2号药量(可选)
-> 准备确认 -> 进罐 -> 插针 -> 抽水
-> 泵1补水/水泵循环 -> 回针/回罐
-> 换罐(两瓶时) -> 活度检测 -> 排气 -> 冲洗 -> 配药完成

本机发药：
发药设置 -> 泵2发药 -> 泵1冲洗 -> 回待机

单独排气：
待机按定量排气 -> 泵2排气 -> 回待机

单独清空/冲洗：
待机按清空 -> 泵1冲洗/排空 -> 回待机
```

要点：当前 LCD 说明对应现有程序，不再是纯 UI 壳。本机配药、发药、单独排气、单独清空/冲洗都会通过 `MachineControl()` 进入实际 `machine` 流程。
