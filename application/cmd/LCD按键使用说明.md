# LCD 按键使用说明

本文按当前 `MachineCMD`、`MachineCMD_Text` 和 `Keyboard` 的实际代码整理，用来说明 LCD 页面、按键入口和页面变化。

> 说明：LCD 使用 ST7920 12864 文本模式。程序里的中文文案按 GB2312 字节表发送，本文直接写中文，方便查看。

> 注意：当前 `machine.c` 中还有上电自动执行的阀门/抽水泵五轮测试流程。这个流程不属于 LCD 按键 UI 控制，实际整机使用前如果不需要测试，应在 `machine` 层关闭或改成按键触发。

## 1. 上电启动

系统上电后，`MachineCMD_Init()` 进入开机初始化页，并保持约 2 秒。

LCD 显示：

```text
自动核素分药仪
系统初始化中..
读取EEPROM...
【就绪】
```

2 秒后自动进入启动就绪页。

LCD 显示：

```text
自动核素分药仪
系统启动就绪
按任意按键启动

```

启动就绪页按任意按键后进入待机页。这个按键只用于确认启动，不继续执行按键本身的功能。

## 2. 通用按键

除启动就绪页外，按【复位】执行统一退出逻辑：

- 清空当前数字输入；
- 关闭手动调试输出；
- 返回待机页。

配药量设置页和发药量设置页中，数字键和小数点作为数值输入：

| 按键 | 动作 |
| --- | --- |
| 【0】~【9】 | 追加到当前输入框 |
| 【.】 | 输入小数点；如果第一个按下，会自动补成 `0.` |
| 【清除】 | 清空当前输入框 |
| 【启动】 | 确认当前输入 |
| 【复位】 | 放弃输入并返回待机页 |

当前输入最多 5 个字符，例如 `99.99`。程序内部按 `0.01 ml` 存储，例如输入 `2.50`，保存值为 `250`。

## 3. 待机页

启动就绪页确认后进入待机页。

LCD 显示：

```text
状态：待机中
浓度:000.0mCi/ml
余量:000.0mCi
体积:000.0ml
```

当前浓度、余量、体积还是固定占位值，后续接入活度计和业务状态后再替换为实时数据。

待机页按键入口：

| 按键 | 进入页面 | 说明 |
| --- | --- | --- |
| 【配药】 | 配药量设置页 | 输入本次配药量 |
| 【发药】 | 发药量设置页 | 输入目标发药体积 |
| 【清空】 | 自动清洗页 | 显示管路冲洗排空提示 |
| 【故障】 | 报警页 | 显示当前预留报警页面 |
| 【进罐】 | 手动控制页 | 最后动作显示“进罐导轨” |
| 【出罐】 | 手动控制页 | 最后动作显示“出罐导轨” |
| 【插针】 | 手动控制页 | 最后动作显示“插针” |
| 【收针】 | 手动控制页 | 最后动作显示“收针” |
| 【抽药】 | 手动控制页 | 最后动作显示“抽药” |
| 【定量排气】 | 手动控制页 | 最后动作显示“定量排气” |
| 【远控】 | 手动控制页 | 最后动作显示“上位机远控” |
| 【1】【2】【4】【5】 | 手动控制页 | 直接翻转水进、药进、水出、药出开关 |

## 4. 配药量设置页

在待机页按【配药】进入。

LCD 显示：

```text
《配药量设置》
配药量:____ml
数字键输入
按启动键开始
```

配药输入逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到配药量输入框 |
| 【.】 | 输入小数点 |
| 【清除】 | 清空配药量输入框 |
| 【启动】 | 保存当前配药量，进入配药运行提示页 |
| 【复位】 | 放弃输入，返回待机页 |

当前代码每次只输入一瓶的配药量，不再显示瓶 2、瓶 3。

## 5. 配药运行提示页

配药量设置页按【启动】后进入。

LCD 显示：

```text
配药中：正在进罐
进罐导轨
请放入一号铅罐
按启动键确认
```

配药运行提示页按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 进入活度计测量页 |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

当前这一页主要负责 LCD 提示，真实进罐动作后续应由 `machine` 层状态机接管。

## 6. 活度计测量页

在配药运行提示页按【启动】后进入。该页显示 15 秒倒计时，倒计时结束后自动回到待机页。

LCD 显示：

```text
活度测量中
请等待活度计稳定
倒计时:15s
暂停键挂起流程
```

活度计测量页按键：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

如果从暂停页按【启动】恢复到测量页，当前代码会重新开始 15 秒倒计时。

| 【.】 | 输入小数点 |
| 【清除】 | 清空目标体积输入框 |
| 【启动】 | 保存目标体积，进入发药运行提示页 |

## 8. 发药运行提示页

发药量设置页按【启动】后进入。

LCD 显示：

```text
发药执行中...
泵二正在发药
完成进度：000%
暂停键挂起流程
```

发药运行提示页按键：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

当前完成进度仍是固定占位 `000%`，真实泵运行和进度刷新后续应由业务流程接入。

## 9. 流程暂停页

配药运行页、活度计测量页、发药运行页按【暂停】后进入。

LCD 显示：

```text
! 流程已暂停 !
配药流程中断
启动键继续
复位键终止
```

如果从发药运行页暂停，第 2 行显示：

```text
发药流程中断
```

暂停页按键：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 返回暂停前的运行页或测量页 |
| 【复位】 | 终止当前提示流程，关闭手动输出并返回待机页 |

当前暂停动作会调用 `StepMotor_StopAll()`，并关闭 `MachineCMD` 管理的手动阀泵输出。ISC1000 定量泵的真实暂停还需要后续在 `machine` 层统一接管。

## 10. 手动控制页

在待机页按动作键，或直接按数字【1】【2】【4】【5】进入。

LCD 显示示例：

```text
--手动控制模式--
动作  空闲
1:0 2:0 4:0 5:0
复位键退出手动
```

第 3 行的 `0/1` 表示对应开关状态：

- `0`：关闭；
- `1`：打开。

如果在手动页按数字键，第 2 行会显示最后操作对象和开关状态，例如：

```text
动作  水进开
```

手动控制页按键：

| 按键 | 手动功能 | 当前硬件映射 |
| --- | --- | --- |
| 【1】 | 水进开关翻转 | 水路阀 |
| 【2】 | 药进开关翻转 | 药路阀 |
| 【4】 | 水出开关翻转 | 水路阀 + 抽水泵 |
| 【5】 | 药出开关翻转 | 药路阀 + 抽水泵 |
| 【进罐】 | 更新最后动作 | 显示“进罐导轨” |
| 【出罐】 | 更新最后动作 | 显示“出罐导轨” |
| 【插针】 | 更新最后动作 | 显示“插针” |
| 【收针】 | 更新最后动作 | 显示“收针” |
| 【抽药】 | 更新最后动作 | 显示“抽药” |
| 【定量排气】 | 更新最后动作 | 显示“定量排气” |
| 【远控】 | 更新最后动作 | 显示“上位机远控” |
| 【复位】 | 退出手动页 | 关闭所有手动输出并返回待机页 |

当前手动输出映射规则：

- 水路阀：水进或水出任意一个开关为 `1` 时打开；
- 药路阀：药进或药出任意一个开关为 `1` 时打开；
- 抽水泵：水出或药出任意一个开关为 `1` 时打开。

所以如果同时打开了【1】水进和【4】水出，只关闭【1】时水路阀仍会保持打开，因为【4】还处于打开状态。

## 11. 自动清洗页

在待机页按【清空】进入。

LCD 显示：

```text
<<自动清洗>>
冲洗管道排空...
泵一正在运行
请放置废液杯!
```

当前 `MachineCMD` 只显示自动清洗提示，还没有在本模块内真正启动泵 1。实际冲洗动作后续应由 `machine` 层执行。

自动清洗页按键：

| 按键 | 动作 |
| --- | --- |
| 【复位】 | 退出并返回待机页 |

## 12. 报警页

在待机页按【故障】进入，后续真实报警也可以统一切到该页。

LCD 显示：

```text
! 系统严重报警 !
故障：导轨未到位
泵阀已安全锁定
按【复位】清报警
```

报警页按键：

| 按键 | 动作 |
| --- | --- |
| 【复位】 | 清除当前 UI 报警提示，返回待机页 |

当前报警内容还是固定文案，真实故障源后续需要接入通信超时、导轨未到位、活度计读取失败等状态。

## 13. 远控说明

当前【远控】键只进入手动控制页，并把最后动作显示为“上位机远控”。

这说明程序已经给远控状态预留了 UI 入口，但还没有真正让上位机接管设备。后续扩展时，建议仍由 `Communication` 负责接收 CAN 指令，`MachineCMDTask` 负责命令分发，`machine` 层负责执行动作，`MachineCMD` 只负责显示当前状态。

## 14. 当前按键功能总表

| 按键功能 | 当前用途 |
| --- | --- |
| 【配药】 | 待机页进入配药量设置页 |
| 【发药】 | 待机页进入发药量设置页 |
| 【清空】 | 待机页进入自动清洗页 |
| 【故障】 | 待机页进入报警页 |
| 【进罐】 | 待机页进入手动控制页，显示进罐导轨 |
| 【出罐】 | 待机页进入手动控制页，显示出罐导轨 |
| 【插针】 | 待机页进入手动控制页，显示插针 |
| 【收针】 | 待机页进入手动控制页，显示收针 |
| 【抽药】 | 待机页进入手动控制页，显示抽药 |
| 【定量排气】 | 待机页进入手动控制页，显示定量排气 |
| 【远控】 | 待机页进入手动控制页，显示上位机远控 |
| 【启动】 | 启动就绪页确认启动；设置页确认输入；配药运行页进入测量页；暂停页继续 |
| 【暂停】 | 配药运行、测量、发药运行页进入暂停页 |
| 【清除】 | 配药/发药设置页清空当前输入 |
| 【复位】 | 退出当前页面，关闭手动输出，返回待机页 |
| 数字键【0】~【9】 | 配药/发药设置页作为数值输入 |
| 数字键【1】【2】【4】【5】 | 待机页或手动控制页作为水进、药进、水出、药出开关 |
| 【.】 | 配药/发药设置页输入小数点 |

## 15. 简单操作流程

配药流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按【配药】 -> 输入配药量 -> 按【启动】
     -> 配药运行提示页 -> 按【启动】
     -> 活度计测量页 15 秒 -> 自动回待机页
```

发药流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按【发药】 -> 输入目标体积 -> 按【启动】
     -> 发药运行提示页
```

手动控制流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按动作键或【1】【2】【4】【5】进入手动控制页
     -> 按【1】【2】【4】【5】控制阀/泵开关
     -> 按【复位】关闭输出并返回待机页
```

清洗流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按【清空】 -> 自动清洗提示页
     -> 按【复位】返回待机页
```
