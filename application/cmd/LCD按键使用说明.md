# LCD 按键使用说明

本文按当前 `MachineCMD`、`MachineCMD_Text`、`Keyboard` 和 `machine` 的代码整理，用来说明 LCD 页面、按键入口和页面变化。

> 说明：LCD 使用 ST7920 12864 文本模式，程序中固定中文文案按 GB2312 字节表发送。本文为了阅读方便直接写中文。

> 注意：LCD 单行最大 16 字节。代码中的中文固定文案已经放在 `MachineCMD_Text.c` 字节表里，不要在 C 字符串里直接写 UTF-8 中文，否则屏幕容易乱码。

## 1. 上电启动

系统上电后，`MachineCMD_Init()` 进入开机初始化页，并保持约 2 秒。

LCD 显示：

```text
自动核素分药仪
系统初始化中..
读取EEPROM...
【就绪】
```

2 秒后自动进入启动就绪页。

LCD 显示：

```text
自动核素分药仪
系统启动就绪
按任意按键启动

```

在启动就绪页按任意按键后进入待机页。这个按键只用于确认启动，不会继续执行按键本身的功能。

## 2. 通用按键

除启动就绪页外，按【复位】执行统一退出逻辑：

- 清空当前数字输入；
- 关闭手动调试输出；
- 清除配药/发药确认事件；
- 返回待机页。

在配药参数设置页和发药参数设置页中，数字键和小数点作为数值输入。

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到当前输入框 |
| 【.】 | 输入小数点；如果第一个按下，会自动补成 `0.` |
| 【清除】 | 清空当前输入框 |
| 【启动】 | 确认当前输入 |
| 【复位】 | 放弃输入并返回待机页 |

当前输入最大 5 个字符，例如 `12.5`、`99.99`。程序内部配药/发药体积按 `0.01ml` 存储，浓度按 `0.001mCi/ml` 存储。

## 3. 待机页

启动就绪页确认后进入待机页。

LCD 显示：

```text
状态：待机中
浓度:000.0mCi/ml
余量:000.0mCi
体积:000.0ml
```

当前浓度、余量、体积仍是固定占位值，后续接入真实业务数据后再替换。

待机页按键入口：

| 按键 | 进入页面 | 说明 |
| --- | --- | --- |
| 【配药】 | 配药参数设置页 | 输入原药体积和目标浓度 |
| 【发药】 | 发药参数设置页 | 输入目标发药体积 |
| 【清空】 | 自动清洗页 | 显示管路冲洗排空提示 |
| 【故障】 | 报警页 | 显示预留报警页面 |
| 【进罐】 | 手动控制页 | 最后动作显示“进罐导轨” |
| 【出罐】 | 手动控制页 | 最后动作显示“出罐导轨” |
| 【插针】 | 手动控制页 | 最后动作显示“插针” |
| 【收针】 | 手动控制页 | 最后动作显示“收针” |
| 【抽药】 | 手动控制页 | 最后动作显示“抽药” |
| 【定量排气】 | 手动控制页 | 最后动作显示“定量排气” |
| 【远控】 | 手动控制页 | 最后动作显示“上位机远控” |
| 【1】【2】【4】【5】 | 手动控制页 | 直接翻转水进、药进、水出、药出开关 |

## 4. 配药参数设置页

在待机页按【配药】进入。

LCD 显示：

```text
<<配药参数设置>>
原药:____ml
浓度:____mCi/ml
启动键：下移确认
```

配药参数设置页有两个输入焦点：

- 第一次进入时，焦点在“原药”行；
- 输入原药体积后按【启动】，保存原药体积并切到“浓度”行；
- 输入目标浓度后再按【启动】，确认参数并进入配药运行提示页。

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 写入当前焦点输入框 |
| 【.】 | 输入小数点 |
| 【清除】 | 清空当前焦点输入框 |
| 【启动】 | 第一次保存原药体积并下移；第二次确认浓度并进入配药运行页 |
| 【复位】 | 放弃输入并返回待机页 |

当前代码每次只配一瓶，不再显示瓶 2、瓶 3。`MachineCMD_ConsumePrepConfirmed()` 当前返回的是原药体积，目标浓度已经在 UI 层保存，后续如果业务流程要使用浓度，需要再开放对应读取接口。

## 5. 配药运行提示页

配药参数设置页第二次按【启动】后进入。

LCD 显示：

```text
配药执行中...
当前: 测量活度中
请等待读数稳定
【暂停】挂起流程
```

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 进入活度计测量页 |
| 【发药】 | 进入发药参数设置页 |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

当前 `machine` 层在读到配药确认事件后，会启动组合测试流程：导杆 A 拉 3cm、导杆 B 推 5cm、两个电磁阀打开、300ul 定量泵吸 100ul、抽水泵打开 2 秒，然后等待发药确认。

## 6. 活度计测量页

在配药运行提示页按【启动】后进入。该页显示 15 秒倒计时，倒计时结束后自动回到待机页。

LCD 显示示例：

```text
配药执行中...
请等待读数稳定
倒计时:15s
【暂停】挂起流程
```

如果活度计读取正常，第 2 行会显示实时活度：

```text
活度:12.3mCi
```

如果活度计超时，第 2 行显示：

```text
活度计超时
```

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【发药】 | 进入发药参数设置页 |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

如果从暂停页按【启动】恢复到测量页，当前代码会重新开始 15 秒倒计时。

## 7. 发药参数设置页

在待机页按【发药】进入；也可以在配药运行提示页或活度计测量页按【发药】进入。

LCD 显示：

```text
<<发药参数设置>>
目标:____ml
（余量：120.5ml)
按启动键开始发药
```

当前余量 `120.5ml` 是 UI 层默认占位值，对应 `MACHINE_CMD_DEFAULT_LEFT_ML_X100`。后续接入真实余量时，只需要更新 `left_ml_x100` 的来源。

发药输入逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到目标体积输入框 |
| 【.】 | 输入小数点 |
| 【清除】 | 清空目标体积输入框 |
| 【启动】 | 校验目标体积并进入发药运行页 |
| 【复位】 | 放弃输入并返回待机页 |

如果输入目标体积大于当前余量，程序会清空输入并留在本页，第 4 行显示：

```text
输入超过余量
```

当前还没有接蜂鸣器模块接口，所以这里只做 UI 层拦截，没有真正驱动蜂鸣器。

## 8. 发药运行提示页

发药参数设置页按【启动】并通过余量校验后进入。

LCD 显示：

```text
发药执行中...
泵二正在发药
完成进度：000%
【暂停】挂起流程
```

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

当前完成进度仍是固定占位 `000%`。如果组合测试流程正在等待发药确认，发药量确认后 `machine` 层会继续让 100ul 定量泵吸 20ul，然后结束测试流程。

## 9. 流程暂停页

配药运行页、活度计测量页、发药运行页按【暂停】后进入。

LCD 显示：

```text
! 流程已暂停 !
配药流程中断
启动键继续
复位键终止
```

如果从发药运行页暂停，第 2 行显示：

```text
发药流程中断
```

暂停页按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 返回暂停前的运行页或测量页 |
| 【复位】 | 终止当前提示流程，关闭手动输出并返回待机页 |

进入暂停页时，`MachineCMD` 会调用 `StepMotor_StopAll()`，并关闭自己管理的手动阀泵输出。组合测试流程检测到暂停页后，也会关闭步进电机、电磁阀和抽水泵输出。

## 10. 手动控制页

在待机页按动作键，或直接按数字【1】【2】【4】【5】进入。

LCD 显示示例：

```text
--手动控制模式--
动作  空闲
1:0 2:0 4:0 5:0
复位键退出手动
```

第 3 行的 `0/1` 表示对应开关状态：

- `0`：关闭；
- `1`：打开。

如果在手动页按数字键，第 2 行会显示最后操作对象和开关状态，例如：

```text
动作  水进开
```

手动控制页按键：

| 按键 | 手动功能 | 当前硬件映射 |
| --- | --- | --- |
| 【1】 | 水进开关翻转 | 水路阀 |
| 【2】 | 药进开关翻转 | 药路阀 |
| 【4】 | 水出开关翻转 | 水路阀 + 抽水泵 |
| 【5】 | 药出开关翻转 | 药路阀 + 抽水泵 |
| 【进罐】 | 更新最后动作 | 显示“进罐导轨” |
| 【出罐】 | 更新最后动作 | 显示“出罐导轨” |
| 【插针】 | 更新最后动作 | 显示“插针” |
| 【收针】 | 更新最后动作 | 显示“收针” |
| 【抽药】 | 更新最后动作 | 显示“抽药” |
| 【定量排气】 | 更新最后动作 | 显示“定量排气” |
| 【远控】 | 更新最后动作 | 显示“上位机远控” |
| 【复位】 | 退出手动页 | 关闭所有手动输出并返回待机页 |

当前手动输出映射规则：

- 水路阀：水进或水出任意一个开关为 `1` 时打开；
- 药路阀：药进或药出任意一个开关为 `1` 时打开；
- 抽水泵：水出或药出任意一个开关为 `1` 时打开。

所以如果同时打开了【1】水进和【4】水出，只关闭【1】时水路阀仍会保持打开，因为【4】还处于打开状态。

## 11. 自动清洗页

在待机页按【清空】进入。

LCD 显示：

```text
<<自动清洗>>
冲洗管道排空...
泵一正在运行
请放置废液杯!
```

当前 `MachineCMD` 只显示自动清洗提示，还没有在本模块内真正启动泵 1。实际冲洗动作后续应由 `machine` 层执行。

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【复位】 | 退出并返回待机页 |

## 12. 报警页

在待机页按【故障】进入，后续真实报警也可以统一切到该页。

LCD 显示：

```text
! 系统严重报警 !
故障：导轨未到位
泵阀已安全锁定
按【复位】清报警
```

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【复位】 | 清除当前 UI 报警提示，返回待机页 |

当前报警内容还是固定文案，真实故障源后续需要接入通信超时、导轨未到位、活度计读取失败等状态。

## 13. 远控说明

当前【远控】键只进入手动控制页，并把最后动作显示为“上位机远控”。

这说明 UI 已经给远控状态预留入口，但 `MachineCMD` 本身还没有让上位机真正接管设备。后续扩展时，建议仍由 `Communication` 接收 CAN 指令，`MachineCMDTask` 负责命令分发，`machine` 层负责执行动作，LCD 只显示当前状态。

| 【故障】 | 待机页进入报警页 |

| 【出罐】 | 待机页进入手动控制页，显示出罐导轨 |
| 【插针】 | 待机页进入手动控制页，显示插针 |

## 15. 简单操作流程

配药流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按【配药】 -> 输入原药体积 -> 按【启动】
     -> 输入目标浓度 -> 按【启动】
     -> 配药运行提示页 -> 按【启动】
     -> 活度计测量页 15 秒 -> 自动回待机页
```

发药流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按【发药】 -> 输入目标体积 -> 按【启动】
     -> 如果体积不超过余量，进入发药运行提示页
     -> 如果体积超过余量，清空输入并提示“输入超过余量”
```

手动控制流程：

```text
上电 -> 开机页 2 秒 -> 启动就绪页 -> 任意键 -> 待机页
     -> 按动作键或【1】【2】【4】【5】进入手动控制页
     -> 按【1】【2】【4】【5】控制阀/泵开关
     -> 按【复位】关闭输出并返回待机页
```

当前组合测试流程：

```text
完成配药参数确认
     -> 导杆 A 拉 3cm
     -> 导杆 B 推 5cm
     -> 打开两个电磁阀
     -> 300ul 定量泵吸 100ul
     -> 抽水泵打开 2 秒
     -> 等待发药量确认
     -> 100ul 定量泵吸 20ul
     -> 关闭输出，流程结束
```
