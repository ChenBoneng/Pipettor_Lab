# LCD 按键使用说明

本文按当前 `MachineCMD`、`MachineCMD_Text`、`machine` 和通信控制权逻辑整理，用来说明 LCD 页面、按键入口和页面变化。

> 说明：LCD 使用 ST7920 12864 文本模式，程序中固定中文文案按 GB2312 字节表发送。本文为了阅读方便直接写中文。

> 注意：LCD 单行最大 16 字节。代码中的中文固定文案已经放在 `MachineCMD_Text.c` 字节表里，不要在 C 字符串里直接写 UTF-8 中文，否则屏幕容易乱码。

## 1. 上电启动

系统上电后先进入开机初始化页，并保持约 2 秒。

LCD 显示：

```text
自动核素分药仪
系统初始化中..
读取EEPROM...
【就绪】
```

2 秒后默认进入上位机远控页。当前设备以“上位机控制”为默认模式，本机不再主动显示“按任意按键启动”页面。

如果代码后续从其它路径进入启动就绪保留页，LCD 显示：

```text
自动核素分药仪
系统启动就绪
按任意按键启动

```

在启动就绪保留页按任意键，会进入待机页。

## 2. 通用按键

除开机页和启动就绪保留页外，按【复位】执行统一退出逻辑：

- 清空当前数字输入；
- 关闭手动调试输出；
- 清除配药/发药确认事件；
- 停止当前远控输出；
- 返回待机页。

在上位机远控页中，【复位】表示本机收回控制权：程序会停止远控输出，退出远控模式并返回待机页。

在配药参数设置页和发药参数设置页中，数字键和小数点作为数值输入。

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到当前输入框 |
| 【.】 | 输入小数点；如果第一个按下，会自动补成 `0.` |
| 【清除】 | 清空当前输入框 |
| 【启动】 | 确认当前输入 |
| 【复位】 | 放弃输入并返回待机页 |

当前输入最大 5 个字符，例如 `12.5`、`99.99`。程序内部体积按 `0.01ml` 存储，活度浓度按 `0.001mCi/ml` 存储。

## 3. 上位机远控页

系统上电完成后默认进入上位机远控页。如果已经在待机页，也可以按【远控】重新申请交给上位机控制。

远控页第 1 行通常显示：

```text
--上位机远控--
```

不同控制权状态下，第 2~4 行显示如下。

### 3.1 PC 已控制

```text
--上位机远控--
PC控制中...
暂停键挂起
复位键收回
```

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 停止当前远控输出，保持远控模式，进入本地暂停状态 |
| 【复位】 | 停止所有远控输出，本机收回控制权并返回待机页 |
| 其它本机按键 | 不执行本机流程，避免抢占上位机控制权 |

### 3.2 远控本地暂停

```text
! 远控本地暂停
物理动作已锁定
启动键继续
复位键收回
```

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 解除本地暂停，继续接收上位机动作命令 |
| 【复位】 | 停止所有远控输出，本机收回控制权并返回待机页 |

按【启动】只恢复“允许执行上位机命令”的状态，不会自动恢复暂停前的动作。上位机需要重新下发动作命令。

### 3.3 等待授权

```text
--上位机远控--
等待授权
物理动作已锁定
复位键收回
```

表示下位机还没有完成板卡授权。此时动作类命令不会执行。

### 3.4 远控申请中

```text
--上位机远控--
远控申请中
物理动作已锁定
复位键收回
```

表示本机按【远控】后，正在等待上位机确认控制权。

### 3.5 本地已接管

```text
--上位机远控--
本地已接管
远控键申请
复位键收回
```

表示本机已经收回控制权。如果需要再次交给上位机，应先回到待机页，再按【远控】申请。

### 3.6 上位机急停

上位机急停当前按 `STOP_PROCESS` 进入停机逻辑。下位机会立即停止步进电机、电磁阀、抽水泵和两台定量泵，但暂时不切换 LCD 急停专用页面，LCD 保持当前远控相关显示。

上位机控制泵1/泵2时，如果 Byte3~4 体积为 0，下位机按默认 10 圈点动处理，并通过 `PUMP_DRIVE_STEPS_PER_TURN` 换算成 ISC1000 的 `in/out` 步数；如果 Byte3~4 非 0，则继续按体积 `ul` 换算运动。

## 4. 待机页

默认上电后不会直接进入待机页。只有远控页按【复位】收回本机控制权，或本机流程退出后，才会进入待机页。

LCD 显示：

```text
状态：待机中
浓度:000.0mCi/ml
余量:000.0mCi
体积:000.0ml
```

当前浓度、余量、体积仍是 UI 占位显示，真实业务数据后续再接入。

待机页按键入口：

| 按键 | 进入页面 | 说明 |
| --- | --- | --- |
| 【配药】 | 配药参数设置页 | 输入当前活度浓度、当前体积和目标活度浓度 |
| 【发药】 | 发药参数设置页 | 待机直接发药，泵2按输入体积吸液 |
| 【清空】 | 自动清洗页 | 显示管路冲洗排空提示 |
| 【故障】 | 报警页 | 显示预留报警页面 |
| 【远控】 | 上位机远控页 | 本机停止当前输出，申请交给上位机 |
| 【进罐】 | 手动控制页 | 第 4 行显示“动作：进罐导轨” |
| 【出罐】 | 手动控制页 | 第 4 行显示“动作：出罐导轨” |
| 【插针】 | 手动控制页 | 第 4 行显示“动作：插针” |
| 【收针】 | 手动控制页 | 第 4 行显示“动作：收针” |
| 【抽药】 | 手动控制页 | 第 4 行显示“动作：抽药” |
| 【定量排气】 | 手动控制页 | 第 4 行显示“动作：定量排气” |
| 【1】【2】【4】【5】 | 手动控制页 | 直接翻转水进、药进、水出、药出开关 |

## 5. 配药参数设置页

在待机页按【配药】进入。

LCD 分三步显示：

```text
配药设置1/3
当前浓度(mCi/ml)
> ____
启动下一步
```

```text
配药设置2/3
当前体积(ml)
> ____
启动下一步
```

```text
配药设置3/3
目标浓度(mCi/ml)
> ____
启动开始配药
```

配药参数设置页按向导推进：

- 第 1 步输入当前溶液的活度浓度；
- 第 2 步输入当前体积；
- 第 3 步输入目标活度浓度；
- 每一步只有一个输入框，避免不知道数字会填到哪一行。

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 写入当前焦点输入框 |
| 【.】 | 输入小数点 |
| 【清除】 | 输入框有内容时清空；输入框为空时退回上一项 |
| 【启动】 | 依次确认当前活度浓度、当前体积、目标活度浓度；第三次进入配药运行页 |
| 【复位】 | 放弃输入并返回待机页 |

当前每次只输入一组当前活度浓度、当前体积和目标活度浓度。`MachineCMD_ConsumePrepConfirmed()` 会把这三个参数一起交给 `machine` 层。

## 6. 配药运行提示页

配药参数设置页第三次按【启动】后进入。

LCD 显示：

```text
配药执行中...
当前: 测量活度中
请等待读数稳定
暂停挂起复位终止
```

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 进入活度计测量页 |
| 【发药】 | 只有底层配药流程已经走到等待发药阶段时，才进入发药参数设置页 |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

注意：【发药】不是任何时候都能进入发药页。配药未完成或底层还没到 `WAIT_DISPENSE` 时，按【发药】不会切页，避免配药配一半误发药。

## 7. 活度计测量页

在配药运行提示页按【启动】后进入。该页显示 15 秒倒计时，倒计时结束后自动回到待机页。

LCD 显示示例：

```text
配药执行中...
请等待读数稳定
倒计时:15s
暂停挂起复位终止
```

如果活度计读取正常，第 2 行会显示实时活度：

```text
活度:12.3mCi
```

如果活度计超时，第 2 行显示：

```text
活度计超时
```

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【发药】 | 只有底层配药流程已经走到等待发药阶段时，才进入发药参数设置页 |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

如果从暂停页按【启动】恢复到测量页，当前代码会重新开始 15 秒倒计时。

## 8. 发药参数设置页

有两种入口：

- 待机页按【发药】：直接启动独立发药流程，主要用于单独控制泵2；
- 配药运行页或活度计测量页按【发药】：只有底层组合流程已经完成配药并等待发药时，才允许进入。

LCD 显示：

```text
<<发药参数设置>>
目标:____ml
（余量：000.0ml)
按启动键开始发药
```

当前余量由配药参数计算得到：目标浓度低于当前浓度时，余量 = 原药体积 + 计算出的补水体积；目标浓度不低于当前浓度时，余量 = 原药体积。未完成配药直接进入发药页时，余量默认为 `0.0ml`。

发药输入逻辑：

| 按键 | 动作 |
| --- | --- |
| 数字键【0】~【9】 | 追加到目标体积输入框 |
| 【.】 | 输入小数点 |
| 【清除】 | 清空目标体积输入框 |
| 【启动】 | 校验目标体积并进入发药运行页 |
| 【复位】 | 放弃输入并返回待机页 |

如果输入目标体积大于当前余量，程序会清空输入并留在本页，第 4 行显示：

```text
输入超过余量
```

当前还没有接蜂鸣器模块接口，所以这里只做 UI 层拦截，没有真正驱动蜂鸣器。

## 9. 发药运行提示页

发药参数设置页按【启动】并通过余量校验后进入。

LCD 显示：

```text
发药执行中...
泵二正在发药
完成进度：xxx%
暂停挂起复位终止
```

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【暂停】 | 进入流程暂停页 |
| 【复位】 | 退出并返回待机页 |

完成进度由 machine 层按“泵2已经确认完成的分段体积 / 本次目标体积”计算。底层实际发药逻辑会先使能泵2，再按输入体积分段吸液；泵2单段最大按满行程 100ul 拆分，因此 2ml 会分成 20 段，每段真正完成后进度再推进，避免泵还在转时提前显示 100%。

## 10. 流程暂停页

配药运行页、活度计测量页、发药运行页按【暂停】后进入。

LCD 显示：

```text
! 流程已暂停 !
配药流程中断
启动键继续
复位键终止
```

如果从发药运行页暂停，第 2 行显示：

```text
发药流程中断
```

暂停页按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【启动】 | 返回暂停前的运行页或测量页 |
| 【复位】 | 终止当前提示流程，关闭输出并返回待机页 |

进入暂停页时，`MachineCMD` 会停止步进电机、电磁阀、抽水泵和两台定量泵；`machine` 层检测到暂停页后，也会暂停当前本地组合流程或本地直接发药流程。

## 11. 手动控制页

在待机页按动作键，或直接按数字【1】【2】【4】【5】进入。

LCD 显示示例：

```text
--手动控制模式--
水进：关药进：关
水出：关药出：关
按1245切换
```

第 2、3 行直接显示四个开关状态：

- `关`：关闭；
- `开`：打开。

如果在手动页按动作键，第 4 行会显示刚按下的动作名称，例如：

```text
动作：进罐导轨
```

手动控制页按键：

| 按键 | 手动功能 | 当前硬件映射 |
| --- | --- | --- |
| 【1】 | 水进开关翻转 | 水路阀 |
| 【2】 | 药进开关翻转 | 药路阀 |
| 【4】 | 水出开关翻转 | 水路阀 + 抽水泵 |
| 【5】 | 药出开关翻转 | 药路阀 + 抽水泵 |
| 【进罐】 | 显示动作名称 | 第 4 行显示“动作：进罐导轨” |
| 【出罐】 | 显示动作名称 | 第 4 行显示“动作：出罐导轨” |
| 【插针】 | 显示动作名称 | 第 4 行显示“动作：插针” |
| 【收针】 | 显示动作名称 | 第 4 行显示“动作：收针” |
| 【抽药】 | 显示动作名称 | 第 4 行显示“动作：抽药” |
| 【定量排气】 | 显示动作名称 | 第 4 行显示“动作：定量排气” |
| 【复位】 | 退出手动页 | 关闭所有手动输出并返回待机页 |

当前手动输出映射规则：

- 水路阀：水进或水出任意一个开关为 `1` 时打开；
- 药路阀：药进或药出任意一个开关为 `1` 时打开；
- 抽水泵：水出或药出任意一个开关为 `1` 时打开。

所以如果同时打开了【1】水进和【4】水出，只关闭【1】时水路阀仍会保持打开，因为【4】还处于打开状态。

## 12. 自动清洗页

在待机页按【清空】进入。

LCD 显示：

```text

冲洗管道排空...
泵一正在运行
请放置废液杯!
```

当前 `MachineCMD` 只显示自动清洗提示，还没有在本模块内真正启动泵1。实际冲洗动作后续应由 `machine` 层执行。

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【复位】 | 退出并返回待机页 |

## 13. 报警页

在待机页按【故障】进入，后续真实报警也可以统一切到该页。

LCD 显示：

```text
! 系统严重报警 !
故障：导轨未到位
泵阀已安全锁定
按【复位】清报警
```

按键逻辑：

| 按键 | 动作 |
| --- | --- |
| 【复位】 | 清除当前 UI 报警提示，返回待机页 |

当前报警内容还是固定文案，真实故障源后续需要接入通信超时、导轨未到位、活度计读取失败等状态。

## 15. 简单操作流程

### 15.1 本机配药后发药

```text
上电 -> 开机页 2 秒 -> 上位机远控页 -> 按【复位】收回控制权 -> 待机页
     -> 按【配药】 -> 输入当前活度浓度 -> 按【启动】
     -> 输入当前体积 -> 按【启动】
     -> 输入目标活度浓度 -> 按【启动】
     -> 配药运行提示页 -> 按【启动】
     -> 活度计测量页 15 秒 -> 自动回待机页
     -> 等底层流程完成配药并进入等待发药阶段
     -> 按【发药】 -> 输入目标体积 -> 按【启动】
     -> 泵2按输入体积分段发药
```

### 15.2 待机直接发药

```text
上电 -> 开机页 2 秒 -> 上位机远控页 -> 按【复位】收回控制权 -> 待机页
     -> 按【发药】 -> 输入目标体积 -> 按【启动】
     -> 如果体积不超过余量，进入发药运行提示页
     -> 泵2按输入体积分段吸液
```

### 15.3 手动控制

```text
上电 -> 开机页 2 秒 -> 上位机远控页 -> 按【复位】收回控制权 -> 待机页
     -> 按动作键或【1】【2】【4】【5】进入手动控制页
     -> 按【1】【2】【4】【5】控制阀/泵开关
     -> 按【复位】关闭输出并返回待机页
```

### 15.4 上位机远控

```text
上电 -> 开机页 2 秒 -> 自动进入上位机远控页
     -> 完成授权后显示 PC控制中...
     -> 上位机发送电机/阀/泵/配药/发药命令
     -> 本机按【暂停】停止当前远控动作，但保持远控模式
     -> 本机按【启动】解除本地暂停，等待上位机重新下发动作
     -> 本机按【复位】收回控制权并返回待机页
```

## 16. 当前底层流程摘要

本机配药确认后，`machine` 层当前按以下顺序推进：

```text
进罐导轨（电机A）推 3cm
-> 插针导轨（电机B）推 5cm
-> 抽水泵打开 5s，把当前溶液送入活度计
-> 等待当前溶液读数稳定
-> 按当前活度浓度、当前体积和目标活度浓度计算补水量
-> 打开水路阀
-> 泵1抽取所需纯净水
-> 抽水泵打开 5s，把纯净水送入活度计
-> 等待最终活度稳定
-> 插针导轨（电机B）先回原点
-> 进罐导轨（电机A）再回原点
-> 本机流程等待发药量确认
-> 泵2按确认体积分段吸液
-> 流程结束
```

远程配药由上位机下发补水量和理论最终体积；远程配药完成后直接结束配药流程，不进入本机等待发药页。远程发药通过上位机发药参数单独启动泵2发药流程。
